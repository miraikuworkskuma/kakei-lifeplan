📒 家計管理・ライフプランシート

リベ大(両学長)の考え方をベースにした家計管理シートです。まず「家計管理」タブで毎月の収支を入力すると、貯蓄率・固定費の割合・消費/浪費/投資のバランス・生活防衛資金を自動で診断します。次に「ライフプラン」タブで、その家計をもとに生涯の資産推移をシミュレーションできます。

💾 入力内容はこのブラウザに自動保存されます(サーバーには送信されません)

💰 収入(手取り・月あたり)

額面ではなく手取り(実際に振り込まれる額)を円単位で入力してください。ボーナスは12で割って月額に足すか、「その他」に月割りで入れてください。

収入合計: 0円/月

🏠 固定費(毎月ほぼ同じ額が出ていくもの)

リベ大では固定費の見直しが「貯める力」の最重要ポイントです。各項目を消費・浪費・投資に仕分けしましょう(消費=生活に必要、浪費=なくても困らない・見栄、投資=将来のリターンにつながる)。

保険は生命保険・貯蓄型保険・自動車保険・車両保険を分けて入力できます。年払いは12で割って月額にしてください。

項目金額(円/月)仕分け

固定費合計: 0円/月

🛒 変動費(月によって変わるもの)

直近1〜3ヶ月の平均を入れると実態に近くなります。年払いのもの(車検・保険・帰省など)は12で割って「特別費の積立」に入れるのがおすすめです。

項目金額(円/月)仕分け

変動費合計: 0円/月

🛡️ 資産と生活防衛資金

生活防衛資金は「何かあっても当面暮らせるお金」で、投資とは別に現金で持つのがリベ大の基本です。目安は会社員で生活費の6ヶ月分、フリーランス・自営業で1年分。

📝 あなたの宿題リスト(入力内容から自動で提案)

リベ大の宿題の順番(家計の見える化 → 固定費の削減 → 生活防衛資金 → 投資 → 稼ぐ)に沿って、いま入力されている数字から「どこを改善するといちばん効果が大きいか」を自動で提案します。

    ✂️ 固定費見直しチェックリスト(リベ大の定番)

    効果が大きい順に並べています。1つ見直すだけで年間数万〜数十万円変わることもあります。やったものにチェック✅(保存されます)。

    • スマホを格安SIMにする
      大手キャリア→格安SIM/オンラインプランで1人あたり月5,000円前後の節約になることも。
    • 保険を見直す(必要なのは基本3つだけ)
      リベ大の考え方では、必要な民間保険は「掛け捨て生命保険(扶養家族がいる場合)・火災保険・自動車保険(対人対物無制限)」の3つ。貯蓄型保険・医療保険は公的保険+貯金でカバーが基本。
    • 電気・ガス会社を乗り換える
      比較サイトで数分の手続き。使い方は同じで料金だけ下がることが多い。
    • 車は本当に必要か考える
      車は生涯で数千万円レベルの支出。手放す・カーシェア・中古車一括払いなどの選択肢も。
    • 家賃・住宅ローンを見直す
      賃貸なら更新時の家賃交渉や住み替え、ローンなら借り換えで総額が大きく変わる。
    • 使っていないサブスクを解約する
      月500円でも年6,000円。3ヶ月使っていなければ解約が目安。
    • 税金を最適化する(ふるさと納税・NISA・iDeCo)
      ふるさと納税は実質2,000円で返礼品がもらえる。投資はまずNISAの活用から。

    ⚙️ 基本設定

    年収・年間支出は「家計管理」タブの入力から自動で計算します(上書きしたい場合だけ入力)。金額は万円単位です。

    🎉 ライフイベント(大きな支出の予定)

    結婚・出産・住宅の頭金・車の買い替え・子供の大学費用・リフォームなど、大きな出費を今の価値の万円で追加してください(その年齢の時点でインフレ調整して差し引きます)。

    📋 シミュレーション結果(入力すると自動で更新)

    📈 資産推移(緑の点線 = FIRE基準額: 年間生活費の25年分)

    青い線(資産合計)が緑の点線(生活費25年分 = 4%ルールの目安)を上回ったら、理論上は資産収入だけで生活費をまかなえる「FIRE圏内」です。

    📅 年ごとの詳細(水色 = 退職の年 / 緑 = FIRE圏内 / 赤 = 資産が尽きた年)

    ⚠️ このシミュレーションの前提と注意点

    • 毎年の黒字は、まず生活防衛資金の目標額まで現金に貯め、それを超えた分を投資に回すルールで計算しています(リベ大の「貯める→増やす」の順番)。
    • 赤字の年は投資から取り崩し、投資が尽きたら現金を使います。現金もマイナスになった年が「資産が尽きた年」です。
    • リターンは投資部分にだけかかり、現金は利息0%として扱います。リターンは税引き後のイメージで入力してください(NISA枠内なら非課税)。
    • 4%ルール(生活費25年分)は米国株の過去実績に基づく目安であり、将来を保証するものではありません。
    • 年金はインフレに連動して増える前提です(実際はマクロ経済スライドで実質目減りする可能性があります)。正確な見込み額はねんきんネットで確認を。
    • ライフイベントの金額はその年齢の時点までインフレ調整されます。教育費など長期のものは1年ごとに分けて入れるとより正確です。
    • 税金・社会保険料の変化(退職後の国保など)は年間支出に含める想定です。気になる場合は「年間支出(上書き用)」で調整してください。
